# 🏯 江小创 · 武汉文创 AI 设计师

> **智能体（Agent）类应用** — 基于 ReAct 架构的对话式文创设计智能体

## 📋 项目简介

**江小创**是一个专注于武汉文创产品设计的 AI Agent，兼具**文创设计师**与**文旅策划师**双重身份。它并非传统的"填表单→出结果"工具，而是一个具备**自主决策能力、工具调用能力和交互式迭代能力**的智能体——能像一位真正的设计师那样，先做文化调研，再出设计方案与营销文案，根据用户反馈反复修改，最后生成产品效果图。

### 一句话概括

> 跟江小创聊天，他就会帮你把武汉文化元素设计成文创产品——从构思到出图，不满意就改。

## 🖥️ 二、产品功能与体验（产品完成度 25%）

### 核心功能

1. **对话式交互**：像跟设计师聊天一样，用自然语言描述需求
2. **流式输出**：Agent 的思考过程逐字呈现，不是转圈等待
3. **自主调研**：Agent 自动搜索文化元素的历史背景、视觉符号、配色方案
4. **方案 + 文案**：除产品设计外，还能产出走心营销文案与产品印字（文旅策划师身份）
5. **智能出图**：方案确认后，Agent 自主调用图像生成模型出效果图
6. **交互迭代**：用户说"颜色太暗"，Agent 理解反馈并修改方案
7. **对话留存**：历史对话本地持久化，可随时回看

### 用户操作流程

```
① 选择需求（或直接打字）
   ↓
② Agent 搜索文化资料 ← 🔧 工具调用可见
   ↓
③ Agent 查询设计规范 ← 🔧 工具调用可见
   ↓
④ Agent 流式输出设计方案 ← ✨ 字一个字蹦出来
   ↓
⑤ 用户反馈 → Agent 修改 ← 🔄 交互迭代
   ↓
⑥ Agent 生成产品效果图 ← 🖼️ 图片出现在对话中
```

### 界面设计

- Streamlit 现代化 Web 界面
- 左侧：API 配置 + 快捷元素选择
- 中央：对话流，支持文字 + 图片混合展示
- 实时状态提示：Agent 正在做什么一目了然

## 💡 三、技术创新与示范性（创新性 20%）

### 3.1 ReAct 智能体架构

本项目的核心是一个**自主构建的 ReAct（Reasoning + Acting）Agent 引擎**（`src/agent.py`），不依赖 LangChain 等重型框架：

```
Thought（思考）→ Action（调用工具）→ Observation（观察结果）→ Thought（继续思考）→ ...
```

**为什么自建框架而非用 LangChain？**
- 代码更透明，评委和开发者能看清 Agent 的每一步逻辑
- 更轻量，启动快，适合比赛演示
- 流式输出控制更精细

### 3.2 自主工具调用（Function Calling）

Agent **自主决定**何时调用哪个工具，而非预设流程：

| 工具 | 用途 | Agent 调用时机 |
|------|------|---------------|
| `search_culture` | 搜索武汉文化元素资料 | 收到设计需求后自动查询 |
| `check_design_rules` | 查询产品设计规范 | 确定产品类型后自动查询 |
| `generate_image` | 生成产品效果图 | 用户确认方案后自动出图 |

评委可以在对话中**看到 Agent 的工具调用过程**——这是智能体区别于普通 Chatbot 的核心特征。

### 3.3 文化知识库 + LLM 混合架构

- **结构化知识库**（`src/data/wuhan_culture.json`）：15 个武汉文化元素的标准化数据（历史、符号、配色、关键词）
- **LLM 深度理解**：通义千问（qwen-plus）对武汉文化的语义理解和创意发挥
- **混合优势**：知识库保证文化准确性，LLM 保证创意灵活性

### 3.4 流式推理可视化

Agent 的思考过程**逐字实时输出**（typewriter 效果），评委能直观感受到"AI 正在思考"，而非等待几十秒后突然出现结果。

## 🚀 快速开始

### 环境要求

- Python 3.10+
- 百炼 API Key（[获取地址](https://bailian.console.aliyun.com)，文本生成 + 图片生成共用一个 Key）

### 安装与运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置 API Key
cp .env.example .env
# 编辑 .env，填入你的百炼 API Key（DASHSCOPE_API_KEY）

# 3. 启动
streamlit run app.py

# 4. 打开浏览器访问 http://localhost:8501
```

> 💡 Windows 用户可直接双击 `启动.bat`，它会自动检查 Python、安装依赖、创建 .env 并打开浏览器。
>
> 💡 如果不想编辑 `.env`，也可以在「🔐 API 配置」页面直接输入 API Key（仅保存在当前浏览器会话）。

### 使用指南

1. **快捷模式**：在顶部选择文化元素、风格、产品类型 → 点击「开始设计」
2. **自由对话**：在底部输入框直接打字，如"帮我设计一个藕汤主题的马克杯"
3. **修改反馈**：对方案不满意？直接说"换个配色"、"字体再大一点"
4. **生成图片**：方案满意后说"出图"或"生成图片"，等 10-30 秒

## ⚠️ 常见问题

**Q: 图片生成为什么失败？**
A: 检查百炼 API Key 是否正确配置，以及账户是否开通通义万相、有余额。

**Q: 文本生成报错？**
A: 确认 `DASHSCOPE_API_KEY` 有效，且账户已开通通义千问（qwen-plus）。可在「API 配置」页切换 qwen-max / qwen-turbo 等模型。

**Q: 能接入其他 LLM 吗？**
A: 可以。系统使用 OpenAI 兼容接口，修改 `.env` 中的 `LLM_BASE_URL` 和 `LLM_MODEL`（以及对应的 API Key）即可切换到其他兼容服务。
